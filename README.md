# ⚡ Auto Clicker Neon + SpeedHack

Página de instalação do script Auto Clicker com interface neon verde.

## 📥 Instalação

1. Instale o Tampermonkey
2. Baixe o script clicando no botão "INSTALAR SCRIPT"
3. Ative o script no Tampermonkey

## 🎮 Como usar

- Pressione **F8** em qualquer site para abrir o menu
- Marque a posição onde quer clicar
- Ajuste o intervalo e o SpeedHack (1x a 100x)
- Clique em INICIAR
